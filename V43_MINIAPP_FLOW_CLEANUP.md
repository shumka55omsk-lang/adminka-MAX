# v43-miniapp-flow-cleanup

Изменения mini app:

- Сценарий «Не знаю размеры»: убран шаг загрузки фото. Маршрут: цель → объект → контакты → комментарий и отправка.
- Сценарий «Знаю размеры»: убран шаг загрузки фото. Маршрут: цель → объект → контакты → размеры и тип изделий → комментарий и отправка.
- На финальном шаге убраны кнопки WhatsApp и Telegram.
- В шаге размеров кнопки «Без молний» / «Нужны молнии» заменены на «Глухие» / «Открывающиеся».
- Поле `openingType` передаётся в заявку, уведомление и CRM-историю.
- Расчёт больше не добавляет стоимость молний из mini app.

База Supabase не требует изменений.
