# v41 CRM sizes visible

Исправление для заявок из MAX mini app → CRM мягких окон.

## Что исправлено

- Размеры из сценария **«Знаю размеры»** теперь явно добавляются в текст истории клиента.
- В расчёт CRM размеры сохраняются расширенно: `items`, `totals.windows`, `totals.sizes_text`, `materials.sizes_text`.
- Добавлены совместимые поля для разных старых версий CRM, если такие колонки есть: `windows`, `sizes_text`, `comment`, `data`, `calculation_data`, `raw_payload`.
- Если каких-то дополнительных колонок нет, синхронизация не ломается — они пропускаются.

## Проверка

После деплоя отправьте новую заявку через кнопку **«Узнать стоимость»**. В истории клиента CRM должно быть видно:

```text
Размеры:
Окно 1: 240×249 см — 5.98 м²
```

Старые заявки, созданные до v41, автоматически не изменятся.
