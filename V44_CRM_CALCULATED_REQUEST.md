# v44 — CRM calculated request

Изменения:

- В mini app в сценарии «Знаю размеры» убрана предварительная стоимость на экране клиента.
- Расчёт всё равно выполняется внутри приложения и на сервере, чтобы заявка в CRM была уже с суммой.
- Сервер пересчитывает заявку сам: площадь, изготовление, монтаж, итог, минимальный заказ.
- Учитывается выбор клиента: «С монтажом» / «Только изготовление».
- Учитывается тип изделий: «Глухие» / «Открывающиеся».
- В CRM мягких окон передаются дополнительные поля суммы для дашборда: total, sum, total_sum, total_price, estimated_total, calculated_total, amount и другие — только если такие колонки есть.
- В расчёт CRM передаются признаки фурнитуры: глухие — круглый люверс 10 мм по периметру; открывающиеся — овальный 42×22 по бокам/низу и круглый 10 мм сверху.

Проверка:

```
/api/version
```

Ожидается:

```json
{ "version": "v44-crm-calculated-request" }
```
