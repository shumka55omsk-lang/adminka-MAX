# v54 — удаление заявок из раздела мини-приложения

Добавлена функция очистки старых/пустых заявок в админке MAX.

## Что изменено

- В карточке заявки раздела «Заявки из мини-приложения» добавлена кнопка **Удалить заявку**.
- Добавлен `DELETE /api/miniapp-leads?id=<id>`.
- Удаление убирает запись из `max_miniapp_leads`, то есть из раздела админки MAX.
- Клиенты и расчёты во внешней CRM мягких окон не удаляются.
- Исправлена работа с UUID id заявок: id больше не приводится к Number.
- Если есть дубль в `max_crm_leads` по `miniapp_lead_id`, он удаляется дополнительно, но ошибка этой очистки не ломает основное удаление.

## Проверка

После деплоя откройте:

```text
https://adminka-max.vercel.app/api/version
```

Ожидаемая версия:

```json
"version": "v54-miniapp-lead-delete"
```
