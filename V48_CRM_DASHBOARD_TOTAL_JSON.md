# v48 — CRM dashboard total JSON adapter

Исправление для дашборда старой CRM мягких окон.

Проблема: сумма есть в MAX и в истории/расчёте CRM, но карточка на дашборде показывает 0 ₽.

Что сделано:

- итоговая сумма теперь дублируется внутри JSON `prices`, `totals`, `materials`, `data`, `summary` и других совместимых полей;
- суммы добавлены на уровень каждой позиции `items[]`;
- добавлены старые алиасы: `totalClient`, `clientTotal`, `totalAmount`, `total_for_client`, `payableTotal` и др.;
- история CRM создаётся с типом `calculation`, чтобы старый дашборд мог учитывать её как рассчитанную заявку;
- запись остаётся безопасной: отсутствующие колонки пропускаются, заявка не ломается.

Проверять только новые заявки после Redeploy.
